# KOPPEE — Coffee Shop Website

A responsive coffee shop landing site built with Bootstrap 4. Includes home, menu, services, reservations, testimonials, and contact pages.

## Pages

| Page | File |
|------|------|
| Home | `index.html` |
| About | `about.html` |
| Services | `service.html` |
| Menu | `menu.html` |
| Reservation | `reservation.html` |
| Testimonials | `testimonial.html` |
| Contact | `contact.html` |

## Run locally

Open any `.html` file in your browser, or serve the folder with a static server:

```bash
npx serve .
```

Contact form submission requires PHP (`mail/contact.php`) on a server that supports PHP mail.

## Structure

- `css/style.min.css` — compiled theme styles
- `css/enhancements.css` — UI/UX improvements (animations, sticky nav, accessibility)
- `js/main.js` — interactions and carousels
- `lib/` — third-party libraries (Owl Carousel, Tempus Dominus, etc.)
- `img/` — images and favicon
